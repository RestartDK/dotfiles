Give me a refresher of what has been done in this repo.

Format it as:

1. Start with one short paragraph summarizing the overall work and current state.
2. Then break down the work into several chunks, ordered by importance.
3. For each chunk, explain:
   - what changed
   - why it mattered
   - which files were involved
   - whether it is complete or still needs follow-up
4. Only include code diffs if they are especially important for understanding the change.
5. Use `git status`, `git diff`, recent commits, and any relevant files as needed.
6. Be concise but useful for someone re-entering the task after context loss.
