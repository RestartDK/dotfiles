# Preserve unseen data with a native custodian

Follow the shared [native hc contract](../../../dstack-mode/references/native-agents.md) for role resolution, fresh interactive launch, delivery receipts, callbacks, waiting, and owned-terminal cleanup. These custody rules are stricter than ordinary review rules and take precedence for sealed collectors.

Launch a separate fresh custodian without the optimizer's chat history, development examples, or prior candidate outputs. Resolve the collection role through the host policy or the user's explicit selection. Never fork or resume an optimizer session.

## Give the custodian a bounded brief

Provide these instructions without development examples or prior candidate outputs:

```text
Goal: Prepare and preserve a genuinely unseen evaluation set.
Sources: Approved machines, users, stores, time range, and read-only queries.
Sampling: Frozen inclusion rules, cohorts, counts, and exclusion identifiers.
Grouping: Keep related users, conversations, incidents, and duplicates together.
Labels: Frozen criterion, permitted decisions, and human review procedure.
Budget: Collection, labeling, provider, time, and request stop limits.
Storage: Private case/label location and a separate metadata-only report path.
Access: Approved tools and providers. Never print credentials or raw data publicly.
Forbidden: No production writes, deployments, code changes, new agents, or tuning.
Report: Only counts, source-window coverage, split/group overlap checks, hashes,
        verified-label counts, readiness, blockers, and the human review location.
Delivery: Send only that report or its safe path to the parent's literal address.
Custody: Keep raw cases, labels, rationales, and transcripts out of the optimizer's
         context until the final comparison is complete.
```

Do not let the optimizer inspect the sealed dataset to check whether it is representative. Freeze sampling rules first, and let the custodian check them. Deduplicate against known development identifiers or hashes without returning unseen text.

Let the human inspect and correct labels directly through the existing review interface. Preserve proposals separately from verified labels. Showing prefills makes annotation assisted, even when the dataset remains unseen to the optimizer.

Require immutable dataset and label versions, group membership, collection provenance, and integrity hashes. Keep the status report separate from content-bearing artifacts. Report counts or authentication failures honestly instead of declaring the set ready.

A native process and a private directory provide workflow separation, not a security sandbox. Same-user agents can still access one another's files. For enforced isolation, use an approved separate identity, container, or access-controlled runner. Without that enforcement, call the boundary procedural. Never claim that hc alone makes data inaccessible.

## Wait without exposing the cases

Use `hc wait <address>` for the collector. Handle messages and timeouts as check-ins, not completion. Require a metadata-only start or readiness receipt and the final integrity checks; process creation, `done`, `idle`, or exit does not prove collection succeeded.

Never use `hc read` on a sealed collector or open its session, tool output, logs, cases, or proposed labels in the optimizer's context. A transcript can expose the dataset even when the report does not. For ambiguous delivery, a permission block, or failure without a safe report, let the human inspect the terminal or use a separate custodian. Never blindly resend or bypass a permission dialog.

## Compare and close owned terminals

Freeze the finalist's source identity, model settings, scoring, and pass rule before giving them to the custodian. Let the custodian run both arms against the sealed set with the same protocol. Send prediction inputs without reference labels. Keep predictions separate from scoring.

Receive the permitted final summary and evidence manifest. If the optimizer later inspects content-bearing failures and changes the system, those cases become regression material. Reserve new unseen cases before making another untouched-test claim.

After the handoff is verified and the dataset is saved, close only campaign-owned terminals through the shared lifecycle rules. Preserve case data, sessions, reports, and outputs. Do not stop the shared hc server. A saved sealed bundle does not require a permanently running collector.
