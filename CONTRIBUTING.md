# Contributing

## Bug reports

Reproducible bug reports are welcome. Open an issue with the machine or host, the command you ran, what you expected, and what happened. Include the relevant log output.

## Pull requests

Unsolicited implementation pull requests are closed without review. This repository configures Daniel's machines, and he decides what belongs in it.

Open an issue first and describe the problem you hit. A pull request he asks for, or one that fixes a bug he confirmed, is welcome.
